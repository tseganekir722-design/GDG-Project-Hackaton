# WorkLink Lite 🚀

**WorkLink Lite** is a responsive web application developed for the GDG Hackathon. It aims to streamline the process of finding and posting job services in a user-friendly environment.

## 🌟 Features
*   **Dynamic Dashboard**: A central hub for users to manage their activities.
*   **Job Management**: Easy-to-use interfaces for browsing and posting new job opportunities.
*   **Service Integration**: Dedicated pages for managing various professional services.
*   **User Authentication**: Simple login and registration flow for secure access.

## 🛠️ Tech Stack
*   **Frontend**: HTML5, CSS3, JavaScript
*   **Design**: Modern, responsive UI/UX principles

## 📁 Project Structure
The repository contains the following key files:
*   `index.html` - The landing page of the application.
*   `dashboard.html` - User-specific management dashboard.
*   `jobs.html` & `post-job.html` - Interfaces for viewing and creating job listings.
*   `login.html` - Secure entry point for registered users.
*   `style.css` - Main stylesheet for the application.

## 🚀 Getting Started

### Prerequisites
To run this project locally, you only need a modern web browser.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/tseganekir722-design/GDG-Project-Hackaton
   ```
2. Navigate to the project directory:
   ```bash
   cd GDG-Project-Hackaton
   ```
3. Open `index.html` in your favorite browser.
